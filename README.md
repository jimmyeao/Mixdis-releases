# Mixdis — releases

Downloads for **Mixdis**, a stem-aware DJ mix builder for Windows and macOS (Apple silicon).

- Installers: see [Releases](../../releases).
- `gpu-runtime-v1`: NVIDIA runtime libraries (CUDA, cuDNN, TensorRT) that Mixdis can download for GPU-accelerated stem separation on Windows. The app offers this itself — you normally don't need to download it by hand.

Website: https://mixdis.com

This repository only hosts release assets; the source is private.
